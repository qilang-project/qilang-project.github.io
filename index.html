为什么是奇语言

现代语言该有的,它都有——而且全部用中文表达。

🀄

    打印行("大于10");

    打印行("其他");
}

结构体与方法.qi
类型 用户 {
    字符串 姓名;
    整数 年龄;

闭包与函数值.qi
函数 应用(f: 函数(整数): 整数, x: 整数): 整数 {
    返回 f(x);
}

变量 基数 = 100;
变量 加基数 = 闭包(x: 整数): 整数 {
    返回 x + 基数;   // 捕获环境,ARC 管理
};
打印行(应用(加基数, 5));   // 105
异常处理.qi
函数 除法(a: 整数, b: 整数): 整数 {
    如果 b == 0 { 抛出 "除数不能为零"; }
    返回 a / b;
}

尝试 {
    打印行(除法(10, 0));
} 捕获 错误 {
    打印行("捕获: " + 错误);   // 跨函数传播
} 最终 {
    打印行("清理完成");
}
并发.qi
函数 生产者(信道: 通道<整数>) { 信道 <- 42; }
函数 慢算(x: 整数): 未来<整数> { 返回 x * x; }

变量 信道 = 通道<整数>();
启动 生产者(信道);          // goroutine
打印行(<- 信道);            // 42,阻塞接收
变量 结果值: 整数 = 等待 慢算(5);

1 · 下载 2026.07.03-1

macOS (Apple Silicon) tar.gz · 53MB Linux (x86_64) tar.gz · 58MB Windows (x86_64) zip · 57MB

常见问题

直球回答,不绕弯。

这是玩具项目吗?

不是。奇语言有 LLVM 21 原生后端、ARC 自动内存管理、完整异常机制、Go 风格 M:N 协程、30+ 标准库模块、包管理器 qi get、交叉编译、LSP + VSCode 扩展、测试框架与三平台 CI——外加 155 个可运行示例和用它自己写成的 Web/CLI/Agent 框架。

性能到底如何?

同机实测:fib(40) 0.28s,快过 Go 1.26(0.32s)约 15%,是 Node 24(0.71s)的 2.5 倍;qi-web 147k RPS,达 Go net/http 的 90%,为 Node 单进程的 2 倍。数据可复现,基准脚本在仓库里。

怎么安装?

三种方式:① 下载 2026.07.03-1 预编译包 解压即用;② 一键脚本 curl -fsSL https://raw.githubusercontent.com/qilang-project/qi/main/scripts/install.sh | bash;③ macOS pkg / Windows msi 安装器。macOS 需 Xcode 命令行工具,Linux 需 clang。

这不就是刻板印象里的"中文编程"吗?

刻板印象里的中文编程是图形化拖拽或解释器贴皮。奇语言的中文只在词法层:代码经 LALRPOP 解析、LLVM 21 生成原生机器码,与 Rust/Go 走同一条工业管线。中文关键字消除的是母语者读代码时的翻译损耗,不是替代计算机科学。

内存需要手动管理吗?

不需要。ARC(自动引用计数)默认开启,字符串/结构体/数组/闭包自动回收;QI_RC_REPORT=1 可在退出时打印活跃对象数自查。句柄式资源(JSON/列表/哈希表句柄)仍需手动释放;循环引用不回收(同 Swift),长驻进程注意打破环。

AI / Agent 能直接写奇语言吗?

能,而且是一等公民:llms.txt(速成规则)与 llms-full.txt(完整语言参考)供模型抓取;npx skills add https://github.com/qilang-project/qi-lang 安装 agent skill;文档站有 给 AI / Agent 专页。
