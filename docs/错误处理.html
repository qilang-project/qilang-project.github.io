错误处理

尝试 / 捕获 / 最终

尝试 {
    变量 内容 = IO::读取文件("数据.txt");
    IO.打印行(内容);
} 捕获 错误值 {
    IO.打印行("出错：" + 错误值);
} 最终 {
    IO.打印行("清理完成");
}

返回值约定（FFI）

很多标准库函数用返回值表示成败，约定不完全统一，用前确认：

函数成功失败
读取文件 / 字符串函数结果空串 ""
写入文件 / 追加文件10
设置环境变量1-1
文件大小字节数-1
字符串类 FFI 失败返回空串（不是 NULL），所以 读取文件(...) + "后缀" 拼接是安全的。用 字符串::字节长度(x) == 0 检测失败。
