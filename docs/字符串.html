字符串

字符串模块同时注册为 标准库.字符串 和 标准库.文本，所以 字符串::X 和 文本.X 都能用。

导入 标准库.字符串;

变量 长度 = 字符串::字节长度("你好");      // 6（UTF-8 字节）
变量 字符数 = 字符串::字符数量("你好");      // 2
变量 位置 = 字符串::查找("你好世界", "世界"); // 找不到返回 -1
变量 子 = 字符串::子串("你好世界", 0, 6);
变量 大 = 字符串::转大写("hello");
变量 含 = 字符串::包含("你好世界", "你好");   // 0/1
变量 等 = 字符串::等于("a", "a");           // 0/1
变量 新 = 字符串::替换("a-b", "-", "+");
字符串函数失败（如 null / 非法 UTF-8）返回空串，不是 NULL。
