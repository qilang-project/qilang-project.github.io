奇语 Qi 文档

100% 中文关键字、编译到原生机器码的系统级编程语言。

奇语基于 LLVM 生成原生可执行文件，内置 Go 式 M:N 协程异步运行时，配套编译器、Web 框架、CLI 框架、LLM Agent 框架、语言服务器与完整工具链。

三十秒上手

curl -fsSL https://raw.githubusercontent.com/qilang-project/qi/main/scripts/install.sh | bash
包 主程序;
导入 标准库.输入输出 作为 IO;
函数 入口() { IO.打印行("你好，奇语！"); }
qi run 你好.qi
