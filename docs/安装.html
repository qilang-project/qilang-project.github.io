安装

一键脚本（macOS / Linux）

curl -fsSL https://raw.githubusercontent.com/qilang-project/qi/main/scripts/install.sh | bash

脚本自动探测平台（macos-arm64 / macos-x64 / linux-x64），从 GitHub Releases 拉预编译二进制，装到 /usr/local/bin（无权限自动降级到 $HOME/.local/bin）。

从源码构建

需要 Rust 1.75+、LLVM 15、Clang。

git clone https://github.com/qilang-project/qi.git
cd qi
cargo build --release
# 二进制在 ./target/release/qi
平台装 LLVM 15
Linuxwget https://apt.llvm.org/llvm.sh && sudo ./llvm.sh 15
macOSbrew install llvm@15
