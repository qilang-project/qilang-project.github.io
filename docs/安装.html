安装

一键脚本（macOS / Linux）

curl -fsSL https://raw.githubusercontent.com/qilang-project/qi/main/scripts/install.sh | bash

脚本自动探测平台（macos-arm64 / macos-x64 / linux-x64），从 GitHub Releases 拉预编译二进制，装到 /usr/local/bin（无权限自动降级到 $HOME/.local/bin 并提示加 PATH）。

装到自定义目录：

curl -fsSL .../install.sh | INSTALL_DIR=$HOME/bin bash

从源码构建

需要 Rust 1.75+、LLVM 21、Clang。

git clone https://github.com/qilang-project/qi.git
cd qi
cargo build --release
# 二进制在 ./target/release/qi
平台装 LLVM 21
Linuxwget https://apt.llvm.org/llvm.sh && chmod +x llvm.sh && sudo ./llvm.sh 21
macOSbrew install llvm@21 && export LLVM_SYS_211_PREFIX=$(brew --prefix llvm@21)
验证安装：qi info --version
