基础语法

变量与类型

变量 名字 = "奇语";          // 类型推断
变量 年龄: 整数 = 10;         // 显式类型
常量 PI = 3.14159;            // 常量
类型LLVM
整数i64（默认 64 位）
浮点数double
布尔i1（真 / 假）
字符串UTF-8

函数

函数 加法(x: 整数, y: 整数) : 整数 {
    返回 x + y;
}

控制流

如果 (x > 10) { IO.打印行("大"); } 否则 { IO.打印行("小"); }
当 (计数 < 5) { 计数 = 计数 + 1; }
对于 i 在 0..10 { IO.打印(i); }

结构体与方法（Go 风格）

类型 点 { x: 浮点数, y: 浮点数 }

函数 (自己 点) 模长() : 浮点数 {
    返回 自己.x * 自己.x + 自己.y * 自己.y;
}

保留字地雷

这些是关键字，不能当变量名：结果 类型 选项 通道 尝试 返回 等待 异步 …。改用别名如 结果值 类型名。
