结构体与枚举

结构体

类型 用户 {
    姓名: 字符串,
    年龄: 整数,
}

// 构造（两种写法）
变量 张三 = 新建 用户 { 姓名: "张三", 年龄: 25 };
变量 李四 = (用户 { 姓名: "李四", 年龄: 30 });

// 字段访问
IO.打印行(张三.姓名);
用 类型 或 结构体 声明都行。字段名后跟逗号。

方法

函数 (自己 用户) 介绍() : 字符串 {
    返回 自己.姓名 + "，" + 整数转字符串(自己.年龄) + " 岁";
}

枚举

枚举 状态 {
    就绪,
    运行中,
    完成,
    错误,
}

配合 匹配 使用枚举变体。
