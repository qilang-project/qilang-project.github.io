大模型

标准库 大模型 模块走 OpenAI 兼容协议。更高层的 agent（自动工具派发/流式/重试）用 qi-harness。

底层直连

导入 标准库.大模型 作为 大模型;
导入 标准库.操作系统;

变量 密钥: 字符串 = 操作系统.获取环境变量("QI_LLM_KEY");
变量 会话 = 大模型.创建会话("https://api.deepseek.com", "deepseek-chat", 密钥);  // 端点, 模型, 密钥
大模型.设置配置(会话, "temperature", "0.7");
变量 回复 = 大模型.对话(会话, "你好");
大模型.关闭会话(会话);

用 qi-harness（推荐）

导入 Harness::{ 大模型, 配置系统提示, 开启会话, 创建代理, 简单问, 关闭代理 };
导入 标准库.操作系统;

变量 密钥: 字符串 = 操作系统.获取环境变量("QI_LLM_KEY");
变量 配置 = 大模型("https://api.deepseek.com", 密钥, "deepseek-chat");  // 端点, 密钥, 模型
变量 会话 = 开启会话(配置);
变量 代理值 = 创建代理("助手", 会话);
IO.打印行(简单问(代理值, "用一句话介绍奇语"));
关闭代理(代理值);
密钥从环境变量读，别硬编码：操作系统.获取环境变量("QI_LLM_KEY")。
