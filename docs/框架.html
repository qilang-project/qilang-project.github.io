Web / CLI / Agent 框架

奇语自带三个用奇语写的框架，各有配套 SKILL.md（AI agent 技能）。

qi-web — Web 框架

Express / Fiber 风格，实测 ~122k RPS。路由 获取/提交/整体更新/删除、中间件、路由组、会话。

qi-cli — 命令行框架

Cobra 风格命令树、子命令、持久参数、执行钩子、自动帮助。

qi-harness — LLM Agent 框架

一行 大模型(端点, 密钥, 模型) 配置，自动工具派发循环（并行 tool_calls）、流式、追踪、重试。

导入 Harness::{大模型, 配置系统提示, 开启会话, 创建代理, 简单问, 关闭代理};
变量 配置 = 大模型("https://api.deepseek.com", 密钥, "deepseek-chat");
变量 会话 = 开启会话(配置);
变量 代理值 = 创建代理("助手", 会话);
IO.打印行(简单问(代理值, "用一句话介绍奇语"));
