Web / CLI / Agent 框架

奇语自带三个用奇语写的框架，各有配套 SKILL.md（AI agent 技能）。

qi-web — Web 框架

Express / Fiber 风格，实测 ~147k RPS。

导入 Web::{应用, 上下文, 响应, 创建应用, 配置, 获取, 文本, 运行应用};
函数 处理(上下文值: 上下文) : 响应 { 返回 文本("ok"); }
函数 入口() {
    变量 应用值 = 创建应用();
    应用值 = 配置(应用值, "127.0.0.1", 6790);
    应用值 = 获取(应用值, "/", 处理);
    运行应用(应用值);
}

qi-cli — 命令行框架

Cobra 风格命令树、子命令、持久参数、执行钩子、自动帮助。

qi-harness — LLM Agent 框架

一行 大模型(端点, 密钥, 模型) 配置，自动工具派发循环（并行 tool_calls）、流式、追踪、重试。
