异步与协程

奇语用 未来<T> 类型 + 等待 表达式做异步，底层是 Go 式 M:N 协程调度器（work-stealing）。

函数 异步计算(值: 整数) : 未来<整数> {
    返回 值 * 2;   // 自动包装成 Future
}

函数 入口() {
    变量 结果值: 整数 = 等待 异步计算(21);
    IO.打印行(整数转字符串(结果值));   // 42
}

支持的 Future 类型

  • 未来<整数> / 未来<浮点数> / 未来<布尔> / 未来<字符串>

协程与通道

变量 信道 = 通道<整数>();
启动 发送者(信道);
变量 值 = <- 信道;

Select 多路复用

选择 {
    情况 值 = <- 通道1 { IO.打印(值); }
    情况 文本 = <- 通道2 { IO.打印行(文本); }
}
