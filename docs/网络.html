网络与 HTTP

HTTP 客户端

导入 标准库.HTTP;
变量 响应 = HTTP.获取("https://example.com");
变量 结果值 = HTTP.发送("https://api.example.com", 数据);  // POST
变量 状态码 = HTTP.获取状态码("https://example.com");
HTTP 模块名是大写 HTTP，不是 http。

TCP / UDP

导入 标准库.网络 作为 网络;
变量 连接 = 网络.TCP连接("127.0.0.1", 6759, 5000);  // 主机,端口,超时ms
网络.TCP写入(连接, "你好");
变量 数据 = 网络.TCP读取(连接);
网络.TCP关闭(连接);
要写完整的 HTTP 服务器，用 qi-web 框架（122k RPS）。
