常见问题

“意外的标记 结果 / 类型”

它们是保留字，改用 结果值 / 类型名 等别名。

“标准库.http 找不到”

模块名大小写敏感，用 标准库.HTTP（大写）。

“字符串模块不存在”

字符串 是类型关键字，但字符串模块同时注册为 标准库.字符串 和 标准库.文本，两个都能导入。

读取文件拼接结果为空

文件不存在时 读取文件 返回空串。先用 字符串::字节长度 检测。

重复 _main 符号

多文件项目里只有入口文件的 入口() 会变成 @main，被导入的模块的 入口 保持普通函数符号。

异步看起来没真正并发

复杂控制流内嵌 等待 目前会退化到同步包装（§4-4 状态机 ~70%）。简单 await 是真异步。

端口用什么

示例和部署都用随机高位端口（3076 / 6759 / 43510），别用 8080 / 3000 / 8000。
