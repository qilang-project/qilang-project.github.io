命令行工具

qi 编译器命令支持中英双形式。

命令说明
qi run 文件.qi编译并运行
qi check 文件.qi只检查语法（友好错误信息）
qi compile 文件.qi -o 输出编译成原生可执行文件
qi format 文件.qi -i格式化（就地）
qi info --version编译器信息

对应中文命令：运行 / 检查 / 编译 / 格式化 / 信息。

调试

RUST_LOG=debug qi run 文件.qi   # 详细编译日志
